# CodeAlpha Image Gallery

This is a Frontend Development internship project made for CodeAlpha.

## Overview
A responsive, Pinterest-style image gallery built using HTML, CSS, and JavaScript. Users can browse images in a masonry grid layout, filter them by category, and view them in a full-screen lightbox with next/previous navigation.

## Features
- Pinterest-style masonry grid layout
- Category filter buttons (All, Nature, City, People)
- Lightbox popup with smooth zoom animation
- Next / Previous navigation (mouse click and keyboard arrow keys)
- Hover effects with image zoom and caption overlay
- Fully responsive design for desktop, tablet, and mobile screens

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Run
1. Clone or download this folder.
2. Open `index.html` in any browser, or use VS Code's Live Server extension for a live preview.
