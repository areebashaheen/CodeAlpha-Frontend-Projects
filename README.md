# CodeAlpha Frontend Development Internship

This repository contains all the projects completed as part of the **Frontend Development Internship** at **CodeAlpha**.

## About the Internship
CodeAlpha's Frontend Development internship focuses on building practical, real-world skills in HTML, CSS, and JavaScript through hands-on projects.

## Projects

### 1. Calculator
A fully functional, responsive calculator with support for all basic arithmetic operations and a clean, modern interface.
- **Folder:** [`Calculator`](./Calculator)
- **Live Demo:** https://areebashaheen.github.io/CodeAlpha-Frontend-Projects/Calculator/
- **Tech:** HTML, CSS, JavaScript

### 2. Image Gallery
A Pinterest-style responsive image gallery with category filters, hover effects, and a lightbox with next/previous navigation.
- **Folder:** [`Image-Gallery`](./Image-Gallery)
- **Live Demo:** https://areebashaheen.github.io/CodeAlpha-Frontend-Projects/Image-Gallery/
- **Tech:** HTML, CSS, JavaScript

### 3. Portfolio Website
A modern, responsive personal portfolio website showcasing skills, education, projects, and contact information.
- **Folder:** [`Portfolio`](./Portfolio)
- **Live Demo:** https://areebashaheen.github.io/CodeAlpha-Frontend-Projects/Portfolio/
- **Tech:** HTML, CSS, JavaScript
