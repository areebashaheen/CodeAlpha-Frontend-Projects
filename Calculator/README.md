# 🧮 Calculator

A modern and responsive Calculator web application built using HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship.

## ✨ Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division
- Decimal number support
- Clear (C) functionality
- Delete (DEL) functionality
- Operator precedence support
- Division by zero handling
- Prevention of invalid consecutive operators
- Keyboard support
- Responsive design for desktop and mobile devices
- Smooth hover and button press effects
- Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⌨️ Keyboard Support

- Numbers: `0-9`
- Operators: `+`, `-`, `*`, `/`
- Decimal: `.`
- Calculate: `Enter` or `=`
- Delete: `Backspace` or `Delete`
- Clear: `Escape`
